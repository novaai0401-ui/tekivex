      How this works

      When someone finishes a document in Pyntra, the app can take the file's fingerprint: a short code worked out from every byte of the file. Change one comma and the fingerprint is completely different. The app signs that fingerprint with a key that lives only on the maker's device, and that signed note is the certificate.

      This page works out the fingerprint of the file you choose and compares it with the one in the certificate, then checks the signature. If the maker's app also asked Pyntra's server for a time stamp, the page checks that too. To do so it asks the server for its public key; nothing about your file is sent.

      The certificate holds no part of the file, not even its name, so sharing a certificate reveals nothing about the document.
